#  Gallery

## Descrição
Este projeto apresenta uma página simples sobre a cidade de Curitiba, capital do Paraná, no Brasil. A página contém informações básicas sobre a cidade e utiliza uma folha de estilos CSS para estilização e jQuery para possíveis interações.

## Tecnologias Utilizadas
- HTML
- CSS
- JavaScript
- jQuery
